Why it's built this way

Colour carries meaning, nothing is decorative

Gold #F5B324Rank 1 only. Medal logic — it's earned, never applied for style.
Violet #6B4EFFMovement only: live dots, climbing, the gap, "growing" Spaces.
Red #E8452CTime pressure only: timers, ▼ drops. Never used for errors or accents.
Paper #FAFAF7Light base. Most Gen Z apps go dark; a scoreboard reads better on paper, and it's lighter on budget Android.

Type

Archivo (800) for poll titles — poster weight, because a poll title is a provocation. Space Grotesk for UI. Space Mono for every number, for a functional reason: tabular digits don't jitter when counts tick up live. Numbers changing width mid-animation is the single ugliest thing a live leaderboard can do.

The signature: rows that move

Rank rows animate between positions on recompute (FLIP transform, 340ms). A ▲2 badge flashes on the row that moved. This is the one place motion is spent — everything else is still. That movement is the product: it's what makes someone check back without a notification.

Where FOMO actually lives

  • The gap line — "17 votes behind Verma Ma'am. Share to close the gap." Free, always visible. This is the entire growth engine: it hands the user a reason to share and tells them exactly what sharing achieves.
  • Counts hidden before voting — so nobody just taps the leader, and voting feels like unlocking.
  • Live dot + rising count — proof other people are here right now.
  • Timer in red — the only red on the screen, so it pulls the eye.
  • NEW / ▲ / ▼ badges — the board visibly changed since you last looked.
  • "12/20 members to unlock" — turns an empty Space from a dead end into a recruiting task.

Where the ₹9 sits, and why it doesn't feel extractive

Rank, percentage and the gap are free forever. That's deliberate — those are what create urgency, and hiding them would fight your own growth loop. The ₹9 buys depth: exact counts across all options, the full under-list, and climb velocity. The sheet only appears after the user has voted and scrolled to the locked section — never on arrival, never blocking the core experience.

WhatsApp preview

The OG tags are in this file's <head>. Three things matter: the image must be 1200×630, the title should carry the current leader and vote count (regenerate the OG image periodically so a re-shared link looks alive), and the description should end with a call to act — "Add your own name." WhatsApp caches previews aggressively, so version the image URL when the leader changes.

Performance — non-negotiable on 4G

  • Poll page server-rendered, counts hydrated after paint. Target <1s on 4G.
  • Fonts preconnected + display=swap; system fallback avoids layout shift.
  • Only transform and opacity animate — no layout thrash.
  • Easing is cubic-bezier(.22,1,.36,1) everywhere — fast out, soft landing.
  • 48px minimum touch targets; all primary actions in the bottom third.
  • prefers-reduced-motion respected.

Empty states are instructions, not decoration

A new Space says "12/20 members to unlock results" with a progress bar — a task, not an apology. A poll with no options says "Be the first to add someone." Never "Nothing here yet."
